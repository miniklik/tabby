Tabby

Program do budowania gier 3D w przeglądarce, zbudowany na silniku Tabby. Bez instalacji: cała gra i edytor mieszczą się w jednej karcie przeglądarki.

Z czego jest zbudowany

Tabby korzysta z kilku technologii naraz — każda robi coś innego.

HTML
Szkielet strony. Mówi, co w niej jest: okno gry, przyciski, panele edytora. Sam nic nie robi, tylko układa elementy.
CSS
Wygląd interfejsu: kolory, czcionki, zaokrąglone przyciski, panel inspektora. Zwykle siedzi w tym samym pliku, w znaczniku <style>.
JavaScript
Właściwy kod gry i najważniejsza część. W nim jest wszystko, co się dzieje: ruch postaci, jazda pojazdami, kolizje, kamera, edytor, zapis gry. Kiedy mówimy, że „piszemy grę”, piszemy ją w JavaScript.
Three.js
Biblioteka napisana w JavaScript — gotowy silnik grafiki 3D, ładowany z internetu jedną linijką. Dzięki niej nie trzeba samemu liczyć, jak narysować sześcian w perspektywie. Mówimy „zrób box, postaw tu, ustaw światło”, a ona tłumaczy to na polecenia dla karty graficznej.
WebGL
Najniższa warstwa: sposób, w jaki przeglądarka rozmawia z kartą graficzną. Three.js używa go za nas.
JSON
Nie kod, tylko format danych. Niczego nie wykonuje, tylko opisuje: „box, rozmiar 1×1×1, kolor czerwony, pozycja 0,0,0”. W nim zapisujemy obiekty, sceny i pojazdy.

Format Tabby

Obiekty w Tabby opisujemy własnym formatem: lista parts z kształtami, role dla kół pojazdów i action dla interakcji (napis, światło, drzwi, jazda).

Fachowo taki sposób budowania nazywa się modelowaniem z prymitywów: obiekty składa się z prostych brył — pudełek, walców, kul, stożków — zamiast rzeźbić je jak w Blenderze. Format Tabby to mały, specjalistyczny język opisu kształtów. Właśnie dlatego sztuczna inteligencja tak łatwo tworzy dla Tabby nowe obiekty: tekst to jej naturalne środowisko.

W skrócie: gry piszemy w JavaScript, rysujemy przez Three.js, a obiekty opisujemy w JSON według reguł formatu Tabby. HTML i CSS to opakowanie.
